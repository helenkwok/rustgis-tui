# Changelog

## 0.1.0 (2026-10-15)

- First release: the terminal UI (layers with highlights, the real map picture, the command and tool palette, a tabbed
  Details/Messages/Attributes panel, identify, select, draw and measure, the AI assistant) and the `rustgis-tui` Claude
  Code mod, which shows it in a pane that you and Claude drive together (`--serve` mode). Built against RustGIS 0.2.0.
